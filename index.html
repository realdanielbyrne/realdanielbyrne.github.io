What I've built at RPMx

AI & agents

Agent platform

An MCP tool layer generated from a single OpenAPI contract, with one tool per API operation, and a production agent built on the Claude Agent SDK. The agent reads vendor quotes, invoices, and statements, and drafts purchase orders, work orders, and AP invoices, always inside each user's own ERP and Microsoft 365 permissions.

AI & agents

Benchmarked LLM extraction

Evaluated models on real production statements, then moved to the one that tied for best accuracy, ran fastest, and cost about half a cent per document. Added multi-model fallback and a PDF-text grounding check after A/B tests exposed silent empty extractions.

Finance systems

AP, AR, and billing

Finance systems

Equipment billing

The monthly billing batch used to mean looking up meter readings in vendor portals and checking them against timecards row by row. Now operating hours flow in directly from four equipment manufacturers, get checked against timecards, and outliers surface on their own. It returns an estimated 3–4 hours a day to the billing team and catches both over-bills and under-bills.

Operations

Fleet utilization

Live operating data shows which machines sit idle and which rentals should go back. Interactive billing lets project managers adjust equipment phases before a batch posts, and the batch ties back to the field app for live data.

Platform

In-house timekeeping

Separate flows for office, field, mechanics, and drivers, a live crew board, and Spanish throughout. It went from concept to executive review in one month.
